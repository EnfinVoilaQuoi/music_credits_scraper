## 4. Gate Spotify (CORRECTIFS, relecture du 2026-10-11)

Sur les 14 faux probables : **9 passaient parce qu'un titre contenait
l'autre**, 1 par une durée qui avait suivi l'ID, 4 par des trous de
vocabulaire. Désormais **13/14 refusés** (le 14ᵉ, « Open Arms (just SZA) »,
l'est faute de durée indépendante) :
- `duree_temoin` : seule une durée qui ne doit rien à l'ID corrobore un titre
  différent (source indépendante, ou la colonne si aucune durée n'a été lue
  par l'ID) ; elle dément aussi l'ID au-delà de la tolérance ;
- un titre CONTENU dans l'autre exige cette corroboration — seulement si le
  mot en plus est dans le TITRE PRINCIPAL (`memes_titres_principaux`).
  Mesuré sur la base le 2026-10-15 (audit, 6 325 ID) : la première version
  signalait 16 titres contenus dont 3 faux seulement (« Only », « Rollin' »,
  « Tout c'que j'ai appris ») ; les 13 justes n'ajoutaient qu'une annotation
  (« (& Lil Pump) », « (Prod by Kanye West) », « - Darina », « (Physical
  Edition) », « To… » tronqué). Avec le titre principal : 3 faux gardés,
  12 justes rendus, 1 resté signalé (« Fortnite Chapter 2 Remix The Finale »).

⚠️ **À mesurer sur ta base** : `python scripts/audit_spotify_ids.py` dira
combien d'ID en place le nouveau gate refuserait (les justes à titre
contenu et sans durée indépendante seraient touchés). L'audit charge
désormais les durées OBSERVÉES de chaque fiche : il juge exactement comme le
gate (sans elles, il aurait pris chaque colonne pour un témoin indépendant).
`repair_spotify_ids.py` ne retire toujours que sur les motifs « artiste » et
« variante » : rien n'est retiré automatiquement sur ce nouveau motif.

## 7. Crédits

- **Remix** : quand MusicBrainz connaît le remixeur d'un remix nommé, c'est
  celui du titre **10/10** (36 remix, 25 connus). Code : crédit « Remixer »
  (source `titre`) posé à chaque run discographie, `scripts/crediter_remixeurs.py`
  pour l'existant ; la validation compte le remixeur d'un REMIX comme son
  producteur.
- **Featuring** (contributeurs Deezer, 3 821 pistes) : 410 pistes ont un
  « Featured » sans « feat » dans le titre ; 78 des 87 titres « (feat. X) »
  sans Featured listent X en « Main ». « Featured » est une preuve d'invité,
  « Main » ne réfute rien — le code crédite déjà tous les co-artistes en
  invités : aucun changement.
- **MusicBrainz par ISRC** : rap FR 141/218 ISRC connus (65 %), œuvre liée
  **28/218 (13 %)** ; US 91/95 et 69/95. Pas exploitable pour relier une
  version à son original sur le rap français.
